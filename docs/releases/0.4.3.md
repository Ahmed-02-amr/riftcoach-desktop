# RiftCoach 0.4.3

Released: 2026-07-14

## Automatic ranked journal

- Rank and LP synchronize from the running League Client without a Riot developer API key.
- RiftCoach discovers the League lockfile and keeps its temporary localhost credentials in memory only.
- Solo/Duo and Flex are tracked separately, while the active ranked queue is detected for each recorded match.
- A before-match snapshot is linked to the local session; ranked games retry at 15, 45, and 90 seconds after game end to capture the updated result.
- Auto Journal shows current sync health, last synchronization time, queue, and per-match LP change.
- Manual Rank/LP remains available as a fallback when League is closed or automatic synchronization is disabled.

## Persistence and privacy

SQLite stores the queue, rank, LP, wins/losses, provisional state, source, and synchronization time. League's rotating lockfile password is never persisted. The integration reads localhost client data only and does not inspect memory, packets, hidden information, or game input.

## Validation

- League lockfile parsing and ranked response normalization tests.
- SQLite before/after snapshot persistence test.
- Core settings normalization, desktop typecheck, production build, packaged asset checks, and responsive rendered UI QA.
