# RiftCoach 0.4.0

Released: 2026-07-14

## Highlights

RiftCoach 0.4.0 replaces manual Training Objectives with an automatic coaching Journal. Completed reviews now build a durable history of what the player is doing well, what repeatedly needs attention, and how rank and LP change over time.

The release also refreshes the entire desktop interface with a League-inspired Hextech visual system designed for the application's real window sizes rather than a full-browser dashboard.

## Automatic Journal

- Each completed review records one recurring-strength candidate and one focus-area candidate.
- Journal entries include champion, role, review date, rank, and LP.
- The Journal aggregates repeated report titles to surface the most common strengths and weaknesses.
- A code-native SVG chart plots up to eight recent ranked snapshots across tier and division changes.
- Rank and LP can be updated directly from the Journal or the Player Profile settings.
- Historical rank/LP values remain immutable when the current profile changes.
- Existing reports are imported into the Journal on first load. Because older reports did not store LP, imported entries use the profile configured during the upgrade; future entries are exact review-time snapshots.

## Workflow changes

- Removed Training from primary navigation.
- Removed mission creation from saved reviews.
- Stopped automatic training-goal creation and evaluation after report generation.
- Removed active-goal context from review generation and follow-up chat.
- Legacy `training_goals` and `goal_results` tables remain untouched so upgrades do not destructively discard prior local data.

## Interface refresh

- New navy, aged-gold, parchment, and teal color system.
- Consistent code-native SVG navigation and action icons.
- Sharper panel geometry and typography inspired by competitive game clients without shipping Riot artwork.
- Responsive icon-rail sidebar at narrow desktop sizes.
- Clean reflow at the Electron minimum window size of 960x620.
- Accessible icon-only navigation labels and reduced-motion support.
- Status messages dismiss automatically instead of staying over the page.

## Local data and migration

The migration creates a local `journal_entries` table. Journal content stays in the same local SQLite database as reports and sessions. No new cloud data path is introduced.

Deleting local RiftCoach data now also deletes journal entries. Legacy training rows are also deleted by the existing local-data cleanup operation.
