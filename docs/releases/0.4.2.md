# RiftCoach 0.4.2

Released: 2026-07-14

## Journal quality fix

- ROFL parser/import status can no longer become a player strength.
- Final-stat-only reviews use KDA, CS, vision, role, duration, and team kill participation without inventing unavailable timeline context.
- Unsupported claims about wave state, resets, pathing, positioning, and event timing are replaced with an explicit evidence limitation.
- Existing affected reports and Journal entries are repaired automatically when the Journal loads.
- Riot champion identifiers are formatted for display, including `MasterYi` as `Master Yi`.
- Match/session time is used for the Journal date, while missing Rank/LP is shown as `Not tracked`.

## ROFL visual-data boundary

Offline ROFL parsing reads the unencrypted metadata envelope and final scoreboard. It does not decode the encrypted replay packet stream into frames. Visual coaching is available only when League renders the replay and RiftCoach captures Replay API screenshots or an optional rendered WebM, or when the user supplies a VOD.

## Validation

- Core champion-name regression test.
- AI prompt and report-quality regression tests for final-stat-only ROFL reviews.
- Desktop typecheck and replay setup tests.
- Production desktop build, packaged asset verification, and responsive in-app browser QA.
