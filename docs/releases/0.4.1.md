# RiftCoach 0.4.1

Released: 2026-07-14

## Highlights

RiftCoach 0.4.1 makes League replay reviews useful without depending on the replay client. ROFL and ROFL2 files are now parsed offline for participant and final-match metadata; League playback, Replay API frames, rendered video, and Riot Match-v5 timelines are optional evidence layers.

## Offline ROFL review

- Parses current ROFL2 and legacy ROFL metadata envelopes without decoding the encrypted replay payload.
- Extracts patch, duration, platform/game ID, Riot IDs, PUUIDs, champion, inferred role, team, result, KDA, CS, vision, level, gold, and items.
- Identifies the player from Player Profile > Riot ID and produces normalized snapshots for the existing expert-rule and AI report pipeline.
- Completes the telemetry report when League is missing, the replay is from an incompatible patch, replay launch fails, or Replay API is disabled.

## Optional evidence

- One-click Replay API setup discovers League, backs up `game.cfg`, writes `EnableReplayApi=1`, and verifies the setting.
- Replay API can still seek through the match for League-window screenshots.
- Optional Replay API recording renders a local WebM and imports frames into the review.
- Optional Riot Match-v5 enrichment adds match details, minute frames, kills, objectives, and building events.
- Optional live-match VOD capture records only the League window, without audio or a full-desktop fallback, and attaches it before automatic report generation.

## Validation

- Workspace TypeScript typecheck.
- Core, Riot, storage, AI, API, and desktop test suites.
- Synthetic legacy ROFL and ROFL2 parser fixtures.
- Current-patch ROFL2 metadata parse against a local replay.
- Replay API config mutation tests for CRLF preservation, idempotency, and missing sections.
- ffmpeg League-window command test.
- Production desktop build and packaged renderer verification.
- Responsive in-app browser QA and interaction checks.
